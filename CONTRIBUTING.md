# Contributing

Thanks for your interest in improving these accessibility skills!

## How to Contribute

1. Fork this repository
2. Create a feature branch (`git checkout -b feature/my-improvement`)
3. Make your changes
4. Test the skill in your AI coding assistant to verify it works
5. Commit your changes (`git commit -m 'Add: description of change'`)
6. Push to your branch (`git push origin feature/my-improvement`)
7. Open a Pull Request

## Guidelines

- Keep skills generic — no company-specific references
- Follow the existing SKILL.md frontmatter format
- Test with real Jira stories when possible
- Include WCAG SC references where applicable
- Keep trigger phrases natural and varied

## Reporting Issues

Open a GitHub issue with:
- Which skill is affected
- What you expected to happen
- What actually happened
- Your MCP server setup (which servers are connected)
